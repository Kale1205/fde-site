CMS Media Admin

News、FAQ、共通メディア、注文状況、支払い確認後の納品メールをこのページから管理できます。

重要: このページ自体は公開リポジトリ上の静的ファイルのため、URLを知れば閲覧できます。ただしCMSの書き込みにはGitHubトークンが必要です。トークンはコードやCMSデータへ保存されません。

1. GitHubへ接続

Fine-grained personal access tokenを入力してください。対象リポジトリを Kale1205/fde-site のみに限定し、ContentsをRead and writeにしてください。

この画面ではトークンをlocalStorageへ保存しません。タブを閉じたら再入力が必要です。

Newsを投稿

本文と画像をまとめて登録できます。画像は任意です。画像未設定の場合はNewsデフォルト画像が使われます。

PNG / JPEG / WebP / GIF、8MB以下。画像なしでも投稿できます。
画像を選択すると、ここにプレビューが表示されます。

Newsを編集・削除

既存Newsの本文・カテゴリ・日付・Top News指定・画像をまとめて変更できます。

画像を選ばず保存した場合は現在の画像を維持します。

画像未設定
差し替え画像プレビュー
新しい画像を選択すると表示されます。

共通メディアを管理

Newsデフォルト画像またはInstagram紹介画像を変更できます。

反映先
PNG / JPEG / WebP / GIF、8MB以下。ファイル名はアップロード時に安全な名前へ自動変換します。
画像を選択すると、ここにプレビューが表示されます。

FAQを追加

ContactページのFAQへ新しい質問と回答を追加します。日本語と英語を登録し、その他の言語では英語をフォールバック表示します。

FAQを編集・削除

公開中のFAQを選択して、内容変更または削除できます。

納品書・領収書・インストーラーを送信

支払い確認後に使用する納品メール画面です。購入者へ納品書、領収書、製品インストーラーをまとめて案内します。決済方法が確定するまでは手動実行とします。

セキュリティ: Cloudflare Workerに ADMIN_FULFILLMENT_KEY Secretを設定し、この画面にも同じ値を入力した場合のみ送信できます。キーは保存しません。
