CMS Media Admin

CMSの作業は日本語で行います。News・FAQは日本語で入力し、保存時に英語版を生成して日本語サイトと英語サイトへ反映します。

重要: このページ自体は公開リポジトリ上の静的ファイルです。CMS書き込みにはGitHubトークン、英語版生成にはAdmin fulfillment keyが必要です。どちらもコードやlocalStorageへ保存しません。

1. GitHubへ接続

Fine-grained personal access tokenを入力してください。対象リポジトリを Kale1205/fde-site のみに限定し、ContentsをRead and writeにしてください。

トークンはこの画面に永続保存しません。

Newsを投稿

タイトルと本文は日本語だけ入力します。「Newsを投稿」を押すと英語版を生成してから、日本語版・英語版を1回の保存で反映します。画像は任意です。

PNG / JPEG / WebP / GIF、8MB以下。画像なしでも投稿できます。
画像を選択すると、ここにプレビューが表示されます。

Newsを編集・削除

日本語タイトル・本文・カテゴリ・日付・Top News指定・画像を編集できます。保存時に英語版を再生成し、両サイトへ同時反映します。

画像を選ばず保存した場合は現在の画像を維持します。
