承認済みのプレビューに合わせ、Archive は自主制作素材の繰り返しキャンバス、Stories は架空の制作例10件への一覧としています。個別制作例は `/ja/lp/cases/01.html` から `10.html`。Archive はドラッグ・矢印キーで移動し、拡大率と位置はリセットできます。操作による慣性は動作軽減時に停止し、自動移動は行いません。受付・料金・診断の方針は変更していません。

## Archive・Stories の素材を差し替える

1. **写真だけ差し替える**: [素材画像](../ja/lp/assets/concept-materials.png) は4列×3行の画像シートです。左上から制作例の並び順で該当マスを差し替え、マスの位置と元画像の縦横比を維持します。Archive、Stories、個別制作例で共用しているので、同じ画像が3箇所とも更新されます。[出典・画像情報](../ja/lp/assets/concept-materials.json) も更新します。
2. **案件名や説明を変える**: [制作例データ](../ja/lp/studies.js) が編集元です。素材位置や表示順を変える場合は、[Archiveの配置](../ja/lp/parallel.js) と[表示を生成するコード](../scripts/lp_showcase.mjs) も確認します。公開HTMLは生成物なので直接編集しません。
3. `node scripts/build_lp_pages.mjs` で再生成し、Archive・Stories・個別制作例をスマホとPC幅で確認してからPRを作ります。現行CMSはお知らせ・FAQ向けで、LP素材の差し替えには対応していません。外部の写真や実案件は掲載権限を確認し、架空案件と実績を区別します。

## CMSで制作例の素材を差し替える

1. CMSメニューの「LP制作例」を開き、既存の10件から案件を選ぶ。公開ID・詳細URLは変えない。
2. 名前、紹介文、読み上げ用の説明、Storiesの掲載順を編集する。必要な写真（JPEG / PNG / WebP、最大4 MB）と動画（MP4、最大12 MB・30秒、互換性のためH.264推奨）を選ぶ。動画には別途、表紙画像が必要。ArchiveとStoriesは静止画または動画の表紙を使い、動画は素材詳細・制作例詳細のプレーヤーで操作したときだけ再生される。動画の内容に必要な字幕は動画に付けてから登録する。
3. 下書きはこのブラウザーだけに保存される。「変更をプレビュー」で表示と掲載順を確認する。
4. 公開できる素材だけを確認してから、CMSの既存GitHub接続を利用して「公開依頼（PR）」を押す。入力した素材はこの操作で公開リポジトリの専用ブランチに送られるため、未公開・個人情報入りの素材は含めない。権限は従来どおり。サイト反映は確認・マージ後で、CMSは直接mainに書き込まない。

公開設定は `ja/lp/media-manifest.json`、差し替え素材は `ja/lp/assets/cases/` の案件別フォルダー。差し替えを解除しても、以前公開したファイルはGitの履歴から削除しない。既存の架空素材と受付停止設定はそのまま維持する。
