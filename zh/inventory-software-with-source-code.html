05 / FAQ

源代码问题

01哪些FDE IMS产品计划包括源代码?

FDE IMS License Plus计划包括完整的源代码. 标准许可不包括源代码或源级修改权.

02FDE IMS License Plus开源软件吗?

否。计划中的源代码访问由购买法律实体内部使用. 版权和许可通知必须保留,不允许公开发行。

03许可加客户可以修改代码吗?

计划允许内部修改。 采购人将负责其修改、兼容性、更新和安全。

04源代码或修改后的版本能否被转售?

否. 计划继续禁止转让、再分配、未经授权转让和分License,包括修改后的版本。
