FDE IMS/ソースコード

ソース権利 / LICENSE PLUS

ソースコード提供を含む在庫管理システム FDE IMS

License Plusは、購入した法人がFDE IMSのソースコードを確認し、自社の内部利用に合わせて改変するための商品として計画しています。

提供予定・開発中 · ソース納品と購入機能は利用できません

01 / 要点

ソース提供には利用範囲がある

ソースコードを受け取ることと、知的財産権を取得すること、公開・再配布できることは同じではありません。
01

ソース一式を予定

License Plusには、FDE IMSのソースコード一式と技術資料を含める予定です。

02

社内向け改変

最終的なLicense Agreementと必要表示を守り、購入法人内で改変版を利用できる予定です。

03

購入者が保守

ソース改変、機能、互換性、更新、セキュリティは購入者が管理します。Updates特典はありません。

02 / 提供予定範囲

License Plusで提供を予定しているもの

予定価格は99,800円・買い切りです。製品本体は開発中であり、最終的なソース一式、技術資料、納品方法、動作要件は完成していません。

コード

確認・編集・拡張

購入法人の内部利用を目的として、ソースコードの確認、編集、拡張、連携を認める予定です。

技術資料

構築と運用の情報

構築、導入、データベース、API、バックアップ／復元資料を提供予定です。最終内容は開発中です。

外部開発者

条件を揃えた委託

秘密保持義務と同じ利用制限を守る外部開発者へ委託できる予定です。一般公開や無制限の第三者アクセスは認めません。

03 / 制限

ソース付きでもオープンソースではない

Baked Kale FDEが計画しているのは社内改変のためのアクセスです。著作権の移転や、FDE IMSを別商品として事業化する権利は含みません。

禁止する予定

再販売・再配布は不可

  • 原版・改変版の販売や再販売
  • 公開リポジトリや公開ファイル共有
  • 無断譲渡やサブライセンス
  • 第三者向けSaaS、貸与、ホスティング、サービス提供
購入者の責任

改変後は自社で管理

  • 社内改変とその動作
  • 互換性、更新、セキュリティ
  • 著作権・ライセンス・第三者表示の保持
  • OSSと第三者製品それぞれの利用条件

FDE IMS License Plusは開発中です。ソース一式、Installer、顧客向け納品経路はまだ利用できず、このページでは納品日を約束していません。

05 / FAQ

ソースコードに関する質問

01FDE IMSでソースコードを含む予定の商品はどれですか？

FDE IMS License Plusでソースコード一式を提供する予定です。通常のLicenseには、ソースコードとソースレベルの改変権を含みません。

02FDE IMS License Plusはオープンソースですか？

いいえ。ソースコードは購入した法人内で利用するために提供する予定です。著作権・ライセンス表示を保持し、公開や再配布はできません。

03License Plusではソースコードを社内で改変できますか？

社内利用のための改変を認める予定です。改変内容、互換性、更新、セキュリティは購入者が管理します。

04ソースコードや改変版を再販売できますか？

いいえ。改変版を含め、再販売、再配布、無断譲渡、サブライセンスは禁止する予定です。
