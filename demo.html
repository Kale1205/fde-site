Native app: in development

Planned launch support is Windows only. Supported Windows versions and system requirements will be published before sales open. iOS and iPadOS versions are planned for future support, with no confirmed release date. macOS is not supported. Upgrade, restore and recovery are not available in the current development build.

This preview uses synthetic sample data in page memory only. Refreshing or resetting the page discards every change. It does not establish completion, security validation or release of the native app.
