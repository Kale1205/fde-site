DEPLOYMENT GUIDE / LICENSE PLUS

Self-hosted inventory management with FDE IMS

FDE IMS License Plus is being designed for customer-server/self-hosted operation. This is a planned deployment direction, not an available or completed production capability.

In development · No production installer or customer deployment is available

01 / QUICK ANSWER

Self-hosted means customer-managed

The purchaser controls the planned environment and also carries the operating responsibility that comes with it.
01

Customer-server/self-hosted operation is planned for License Plus, alongside full source code and technical documentation.

02

03

02 / RESPONSIBILITY

Know what stays with the purchaser

Self-hosting changes where the software is planned to run and who operates it. It does not add a managed cloud service, dedicated recovery service, or Baked Kale FDE support SLA.

INFRASTRUCTURE

Server and hosting

The purchaser is planned to provide and manage the customer-server environment. Final supported platforms and requirements are not confirmed.

MAINTENANCE

Updates and security

License Plus does not include the License Updates add-on. The purchaser manages its version, source changes, compatibility, and security.

CONTINUITY

Backup and recovery

The purchaser is planned to manage backups and recovery. Technical documentation is planned, but validated procedures and final support boundaries remain under development.

03 / BEFORE DEPLOYMENT

Questions that still need final answers

A responsible self-hosted decision depends on requirements and operating evidence that are not yet final. This page intentionally does not claim a ready installer, validated platform list, uptime commitment, or production support model.

TECHNICAL FIT

Environment and integration

  • Supported server and client platforms
  • Network and authentication requirements
  • Database and API deployment steps
  • Validated backup and restore procedure
OPERATING FIT

Ownership after deployment

  • Who applies source and configuration changes
  • Who monitors compatibility and security
  • Who responds to incidents and restores data
  • What support, if any, is included in final terms

Self-hosted operation is a planned License Plus capability. FDE IMS remains pre-release, and no statement on this page should be read as current availability or a production deployment commitment.

05 / FAQ

Self-hosted questions

01Is self-hosted operation planned for every FDE IMS product?

No. Customer-server/self-hosted operation is planned for FDE IMS License Plus. It is not a confirmed deployment option for the standard License.

02Who manages a planned License Plus self-hosted environment?

The purchaser is planned to manage its infrastructure, source changes, compatibility, updates, security, and backups. Final deployment and support terms are not yet defined.

03Are the server and operating requirements confirmed?

No. Supported environments, deployment steps, backup and restore procedures, hosting requirements, and service levels remain under development.

04Can FDE IMS License Plus be deployed now?

No. FDE IMS is in development. The production installer, customer distribution, public purchasing, and deployment path are not available.
