FDE IMS

FDE IMS — Two product models

License and Updates are different operating models with different rights, source-code availability and update responsibilities.

License

FDE IMS License

Planned price
¥49,800 one-time

Perpetual internal-use license with source code. The purchasing legal entity may customize it for its own internal business use.

  • Source code included
  • Perpetual internal-use license
  • Internal customization allowed
  • External developers may assist under license/confidentiality terms
  • Updates and security are generally customer-managed

No resale, redistribution, sublicensing, unauthorized transfer or third-party SaaS/service provision. Customization freedom ≠ redistribution rights.

License rights & restrictionsAsk about formal availability
Updates

FDE IMS Updates

Planned price
¥9,800 / month

Subscription product continuously updated by FDE for functionality, security and compatibility. Source code is not provided.

  • Continuous updates by FDE
  • Function, security and compatibility improvements
  • No source code delivery
  • Use during active subscription only
  • Update operations managed by FDE

Formal update cadence, versioning and service terms are not yet finalized.
