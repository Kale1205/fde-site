Security & deployment

企業データをどこに置くかまで設計する。

Web型だけでなく、企業のセキュリティ要件に合わせたローカル運用・配布型も視野に入れます。

Local / Self-hosted

社内PCや社内環境で動かし、業務データを外部クラウドへ送らない構成を選択可能にする方針です。

ローカルDB構成
ソースコード引き渡し
アクセス権限・監査ログ

Web / Managed

ブラウザ利用を優先する場合は、認証・暗号化・バックアップ・権限分離を前提に設計します。

HTTPS / encryption
Role-based access control
Backup / audit logging
