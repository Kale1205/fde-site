FDE IMS

Two product models

License and Updates are designed for different ownership, source-code and maintenance needs.

License

FDE IMS License

Estimated price
$313 one-time

A perpetual internal-use license with source code. The purchasing legal entity may customize the software for its own internal business use.

  • Source code included
  • Perpetual internal-use rights
  • Internal customization allowed
  • External developers may assist under license and confidentiality terms
  • Updates and security are generally customer-managed

Resale, redistribution, sublicensing, unauthorized transfer and third-party SaaS or service provision are not permitted.

Review license termsAsk about availability
Updates

FDE IMS Updates

Estimated price
$62 / month

A subscription plan with ongoing functionality, security and compatibility updates managed by FDE. Source code is not included.

  • Ongoing updates managed by FDE
  • Functionality, security and compatibility improvements
  • No source code delivery
  • Access tied to an active subscription
  • Update operations managed by FDE

Update cadence, versioning and final service terms are still being defined.
