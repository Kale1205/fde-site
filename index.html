How it works

導入は3ステップ。

01

契約方法を選ぶ

買い切り、またはアップデート・保守付きの月額プランから選びます。

02

PCへ導入する

社内PCにインストールし、ローカル環境を中心に運用を始めます。

03

必要に応じて更新する

月額プランでは、新機能・修正・セキュリティ改善を継続して受け取れます。

Security & Deployment

デスクトップ型・ローカル運用を基本に。

常時クラウド接続を前提とせず、企業PCで動くデスクトップアプリケーションとして設計します。

Local-first data

在庫や取引先などの業務データは、企業側の端末・ローカル環境で扱う構成を基本とします。

Desktop application

日常操作は専用デスクトップアプリから行い、Webログインを必須としない運用を想定します。

Controlled updates

アップデートは配布パッケージとして管理し、導入企業が適用タイミングを決められる方式を目指します。

Audit & permissions

権限分離、操作履歴、バックアップなど、業務ソフトに必要な管理機能を段階的に整備します。
